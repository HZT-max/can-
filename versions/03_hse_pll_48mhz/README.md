# 03：切换到 HSE + PLL 48 MHz

相对已验证的 `02`，只加入系统时钟层：

```text
板载8 MHz HSE -> 预分频1 -> PLL倍频6 -> 48 MHz SYSCLK
```

这与当前 AP/ChibiOS 板级定义使用的时钟来源和频率一致。CAN、UART、定时器中断、操作系统和动态内存仍未加入。

为了让肉眼看到的闪烁速度接近之前版本，空循环计数由 `700000` 按6倍主频同步调整为 `4200000`；这不增加新的功能层。

观察结果：

- 实物已验证：RUN 持续闪烁，HSE起振、PLL锁定和48 MHz系统时钟切换成功。
- RUN 常亮：时钟初始化中的某一步超时。
- RUN不亮：程序未运行到PB1配置位置。

烧录文件为 `firmware.bin`，地址为 `0x08000000`。
